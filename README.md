# PAPP by Oleksiy Babanskyy

English Markdown guides for working with an assistant on research, mathematics,
software and practical projects. Keep the result connected to its materials,
checks and limits, with a clear place to resume.

## Start with your task

Open [START HERE](kit/START_HERE.md) and the [short core](kit/PAPP.md), or supply
them to your assistant. Keep the complete folder available. If the assistant
cannot open a referenced guide, provide that file when needed.

> Use PAPP to help me with [goal]. Start from the materials and work already
> available in [location, if known]. Read START HERE and the core, choose the
> guidance this task needs, produce a useful first result, and leave a clear
> checkpoint and next action.

You do not need to read every guide before beginning. The assistant starts
from your request and existing work, then consults relevant modules.
Use this folder directly; versioned downloads, when published, belong in the
repository's Releases section. No installer is required or included.

## A small example

This is an illustration, not an observed use trial.

**Request:** compare two supplied reports about a building and draft a timeline.
**Result:** a short timeline with source references and one disputed date marked
unresolved. **Checkpoint:** draft delivered; do not rely on that unresolved date.
**Later request:** include architectural changes only, excluding ownership changes.
The assistant revises the affected entries and references, retaining relevant
uncertainty and the earlier scope.

## What the work needs

Use the guidance for software, documentary research, empirical research,
mathematics or organisation when it is relevant. Combine modules for mixed
work. [START HERE](kit/START_HERE.md) gives the reading routes.

For brief work, the answer can carry the account. Shared or resumed work needs
an accessible checkpoint and a responsible person or role. For a new project,
the assistant creates useful files only when authorised and file tools are
available. With chat-only tools, it returns content you can save.
[Workspace guidance](kit/WORKSPACE.md) explains setup and travelling copies.

The optional atlas is a manually maintained map to sources and relationships.
Add it for a concrete navigation need. This edition includes no atlas generator,
graphics, plugin or automatic source reconciliation.

## See an example and understand the limits

The completed [OPERA before/after example](examples/opera/README.md) illustrates
a manually reconciled source change. It is an assisted retrospective account;
it does not establish general productivity or independent scientific validation.
[Edition scope](EDITION.md) describes the evidence and limitations.

Keep existing project agreements and required records. See
[the working agreement](kit/CONTRACT.md), [compatibility](kit/COMPATIBILITY.md)
and [manual upkeep](MAINTENANCE.md).
