# What this edition offers

Delivery identity: **PAPP/github-1.0.3**.
Guide and working-agreement identity: **PAPP/documentary-1.0.3**.

This is portable English Markdown guidance for authorised research,
mathematics, software and organised work. It offers one entry, modules read
on need, a sufficient project account and manual upkeep. Existing project
agreements and required records remain authoritative. Choosing this guide
does not claim conformance to another governing method.

The core preserves purpose and completion; materials and assumptions; actual
work and checks; conclusion, conditions and limits; current checkpoint,
responsible role and next action. These meanings can live in one existing
note, issue, report or notebook. The guidance imposes no universal folder
count, extra ledger or atlas application.

This revision clarifies the intended contribution before substantial work and
the final handoff, preserving authorisation and a sufficient existing account.
Text and package checks do not establish future user or assistant behaviour.

The ordinary workflow in README is illustrative, not another use experiment.

The completed OPERA example supports one assisted retrospective documentary
cycle. A reader self-reported finding four items in the exact original first
note without help. A fresh-context assistant and coordinator reconciled a
revised source. That does not establish everyday ease, comparative
productivity, general effectiveness or independent scientific validation.
Selected guides were exercised; all modules were not tested. This delivery
contains portable adaptations, with no new usability observation of them.

Optional atlas guidance is manual. This package contains no atlas generator,
graphics, installer, plugin adapter, host certification, automatic semantic
update or runtime security control. Source PDFs are linked, not bundled;
access grants no redistribution permission.

## Package receipts and publication

A paired package receipt identifies the prepared ZIP and manifest. Its phase
and status describe that preparation snapshot; they are not a live statement
of publication or permission. An older receipt can therefore retain local,
`false` or `NONE` preparation fields after the same bytes have been published.
For the release record of this edition, see
[v1.0.3](https://github.com/aconsciousfractal/papp/releases/tag/v1.0.3).
The receipt and the ZIP can be checked together without opening that page;
checking their hashes does not itself establish current publication status.
